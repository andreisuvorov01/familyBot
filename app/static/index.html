Как пользоваться

📝 Задачи в чате

Напишите боту сообщение с префиксом:

  • л — личная задача, с — общая семейная
  • !, !!, !!! — приоритет

Пример: с Купить молоко завтра в 15:00 !!

👆 Жесты

  • Нажмите на кружок, чтобы выполнить задачу
  • Смахните вправо — выполнить, влево — удалить
  • Потяните окно вниз, чтобы закрыть его

🤝 Семья

Общие задачи видят оба партнёра, личные — только автор. При создании и выполнении общей задачи партнёр получает уведомление.

📅 Google Календарь

Подключите его в настройках: задачи с дедлайном появятся в отдельном календаре «FamilyBot». Если перенести событие в календаре, срок задачи тоже изменится.
